# QuizNest - Online Quiz Maker

## About the Project

QuizNest is a responsive online quiz-making platform developed using HTML, CSS, and JavaScript. It allows users to create quizzes, attempt multiple-choice questions, and view their results immediately.

This project was developed for the CODSOFT Web Development Internship, Level 2 Task 2.

## Features

- User registration and login demo
- Create quizzes with multiple-choice questions
- Add four options and select the correct answer
- Browse and search available quizzes
- Display one question at a time
- Calculate scores and percentages automatically
- Show correct answers after quiz completion
- Save quizzes using browser localStorage
- Responsive interface for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Use the sample quizzes or create your own quiz.

You can also use the Live Server extension in VS Code.

## Limitations

This is a front-end demonstration project.
Quiz data and demo accounts are stored locally in
the browser. The application does not use a
backend server or a shared database.

Do not use real passwords with this demo.
